# HotbarBumpers

> Lightweight Fabric mod that adds configurable Next Hotbar Slot and Previous Hotbar Slot keybindings for Minecraft Java Edition 26.2.

HotbarBumpers is a lightweight, client-side Fabric mod for Minecraft Java Edition 26.2.

It adds two configurable keybindings that let you move to the next or previous hotbar slot without using the mouse wheel. The mod uses Minecraft's native hotbar selection logic, providing behavior that matches vanilla gameplay.

## Features

- Adds two configurable keybindings:
  - Next Hotbar Slot
  - Previous Hotbar Slot
- Uses Minecraft's built-in hotbar selection behavior.
- Fully configurable through Minecraft's Controls menu.
- Client-side only.
- Lightweight with no unnecessary mixins.

## Requirements

- Minecraft Java Edition 26.2
- Fabric Loader
- Fabric API

# Quick Start

After installing the mod:

1. Open **Options → Controls → Key Binds**.
2. Find the **HotbarBumpers** category.
3. Bind **Next Hotbar Slot** and **Previous Hotbar Slot** to your preferred keys or mouse buttons.
4. Enjoy quick hotbar navigation without using the mouse wheel.

## Installation

1. Install Fabric Loader for Minecraft 26.2.
2. Install Fabric API.
3. Download the latest HotbarBumpers release.
4. Place the JAR file into your Minecraft `mods` folder.
5. Launch Minecraft and assign your preferred keys in **Options → Controls → Key Binds → HotbarBumpers**.

## Why?

This mod was created to make hotbar navigation easier for players using gaming mice, accessibility devices, custom controllers, or any setup where dedicated hotbar navigation buttons are more convenient than the mouse wheel.
