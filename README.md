# HotbarBumpers

A client-side Fabric mod for Minecraft Java Edition 1.21.1.

## Development setup

- Java 21 (JDK) is required.
- Use `./gradlew build` to build the mod.
- Use `./gradlew runClient` to launch a development copy of Minecraft.

The first feature has not been implemented yet. The project currently contains only its build configuration and Fabric metadata.
